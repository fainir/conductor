conductor - every tool checks its own output (real CLI output)
$ npx tsx src/cli.ts slugify '{"text":"Hello, World!"}'
{ "ok": true, "output": { "slug": "hello-world" }, "attempts": 1,
  "verdict": { "ok": true, "score": 1 }, "costUsd": 0 }

$ npx tsx src/cli.ts normalize_phone '{"phone":"call me"}'
{ "ok": false, "attempts": 1,
  "verdict": { "ok": false, "score": 0,
    "feedback": "shape: normalized must match /^\\+?\\d{6,15}$/ (optional '+', 6-15 digits)" } }

A wrong answer is never passed through: it is retried with the feedback,
handed to a fallback, or returned as a failure the calling model can fix.
